# Лаба — Obsidian и Git-синхронизация

Дата: 2026-08-23

- Obsidian vault расположен на сервере: `/root/hermes-vault`.
- Vault является Git-репозиторием; `git pull --ff-only` выполнен успешно.
- Для синхронизации с ноутбуком: перед чтением заметок выполнять `git pull`; после создания или изменения — `git add`, `git commit` и `git push`.
- Эта заметка создана как проверка рабочего процесса синхронизации.
